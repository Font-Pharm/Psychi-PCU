ผู้ดูแลระบบยังไม่ได้ตั้งลิงก์ระบบ (APP_URL ในไฟล์ docs/index.html)
กำลังเปิดในเบราว์เซอร์ของ LINE หรือแอปอื่น ซึ่งติดตั้งแอปไม่ได้ กรุณากดเมนู ⋮ หรือ ... แล้วเลือก เปิดในเบราว์เซอร์ (Chrome / Safari)

ติดตั้งบน iPhone / iPad

  1. เปิดหน้านี้ด้วย Safari
  2. กดปุ่ม แชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น)
  3. เลือก เพิ่มไปยังหน้าจอโฮม แล้วกด เพิ่ม

ติดตั้งบน Android

  1. เปิดหน้านี้ด้วย Chrome
  2. กดเมนู ⋮ มุมขวาบน
  3. เลือก ติดตั้งแอป หรือ เพิ่มลงในหน้าจอหลัก
